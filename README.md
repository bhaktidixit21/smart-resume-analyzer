# Smart Resume Analyzer

An AI-powered ATS Resume Analyzer built using Python, Streamlit, SQLite, and NLP. It provides secure user authentication, ATS resume analysis, skill detection, resume scoring, job description matching, AI suggestions, PDF report generation, and password recovery using Email OTP.

# Live Demo

https://smart-resume-analyzer-9tutkn552utbdtjvoxexk8.streamlit.app/

# Features

User Registration

Secure Login Authentication

Forgot Password (Email OTP)

Password Reset

Resume PDF Upload

PDF Text Extraction

ATS Resume Section Analysis

Resume Strength Score

Skill Detection

Job Description Matching

AI Resume Improvement Suggestions

Interactive Skill Charts

PDF Resume Analysis Report Download

Secure Logout

# How to Run

Clone the repository

git clone <your-github-link>

Install dependencies

pip install -r requirements.txt

Run the application

streamlit run app.py
